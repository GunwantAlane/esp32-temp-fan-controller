# ESP32 Temperature & Cooling Fan Controller

An embedded system project using an ESP32 microcontroller to monitor ambient temperature via an analog sensor and automatically trigger a cooling fan relay when the temperature exceeds a safe threshold.

## Files
- `firmware.ino`: ESP32 firmware for temperature acquisition, signal filtering, hysteresis control, and serial telemetry.
- `README.md`: Project overview, hardware pinout, and calibration notes.
